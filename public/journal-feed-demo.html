📋 Journal Feed — Patientkort-sektion (demo)

Unified journal-UI: nya CCO-journaler + historiska PDF:er + bilder + samtycken + avtal + asset-statusar. Allt från CCO endpoint /api/v1/cco-customers/:id/journal-feed. Inga Drive-länkar.

Endpointet returnerar: counters, sectionCounts, items[], sections{}, needsAttention[]. Asset-länkar går alltid via /api/v1/cco/assets/:id/download — aldrig direkt Drive-URL.
