Jag kan / vet

  • Jag kan öppna kundkort Söka på namn / telefon / Cliento-id och öppna rätt kort
  • Jag kan verifiera identitet Bekräfta namn + telefon + Cliento-id mot kortets header
  • Jag har gjort testjournal Skapat draft, sparat och sett posten i feed (Training Mode eller pilotkund)
  • Jag kan skapa journal Klicka "Ny anteckning", välja mall, skriva och spara som draft
  • Jag kan signera Gå igenom Pre-Signering Check och klicka Signera
  • Jag har sett rättelseflödet Rättelse = ny post · originalet förblir låst efter signering
  • Jag kan göra rättelse Skapa rättelse som ny post länkad till originalet
  • Jag förstår STOP vid osäker identitet Gissa inte — stoppa skrivandet och fråga kollega/admin innan du fortsätter
  • Jag förstår att review-material inte är klinisk sanning "Behöver granskning", import och foto-review — referens only, inte diagnos/dosering
  • Jag vet när jag ska stoppa Fel patient, trasig feed/timeline, 5xx — pausa alla nya journaler
  • Jag vet vem jag kontaktar Identitet/dubblett → Egzona/admin · Fel patient/GDPR/teknik → Fazli · Se Go-Live Control
