T-8 minSmoke-test

  • Klicka pilotkund 1 från personalstart → ska öppna journal-feed
  • Klicka tillbaka → klicka pilotkund 3 → ska visa signerad post + rättelse
  • Refresh Command Center → ska visa stor grön GO

T-5 minFailover-check

  • Öppna backup-URL i bakgrund: major-arcana-frankfurt.onrender.com/cco-demo.html
  • Om backup laddar 200 → du har failover redo
  • Skriv ner mobilnumret till någon som kan ringa Fazli om något händer

T-2 minSamla personalen

  • Be alla logga in på sin egen station
  • Säg: "Vi börjar med en kontrollerad journalpilot — inget skarpt än"
  • Visa skärmen — personalstart i fullskärm

T-0Starta presentationen

  • Klicka Start på 15-min timern i Presenter Mode
  • Säg: "Det här är CCO — vårt nya kundkort och journalnav."
  • Kör 14-stegs flow från Presenter Mode
  • Bocka av varje steg i Presenter Mode — håller dig på spår
