Vad fungerar end-to-end

📝

Skapa CCO-journal

Draft → signera → auto-PDF i secure storage → asset → blir VISIBLE_ON_PATIENT_CARD → syns under Journaler.

✏

Rättelse (aldrig edit)

Signerad journal kan inte ändras tyst. "Ny rättelse"-knapp skapar ny entry med anledning. Original förblir låst.

📋

Hälsodeklaration · Hair TP

Submit via API → journal-entry + autoSign → PDF + asset med category=form → syns under Formulär på patientkortet.

⚕

Friskförsäkran · TP

Samma flöde som hälsodeklaration. Formulär-sektion på patientkortet visar båda PDF:erna med signering + tamper-hash.

🕐

Tidslinje · 7+ event-typer

Kronologisk feed: form_submitted · form_signed · pdf_archived · correction_created · asset_imported · asset_status_transition.

🧵

Original ↔ rättelse-tråd

Thread-banner i tidslinjen visar original-poster bundlade med sina rättelser och anledning.

⛔

6 asset-statusar

VISIBLE_ON_PATIENT_CARD · VERIFIED_IN_CCO · NEEDS_REVIEW · LINK_ONLY_BLOCKER · FAILED_IMPORT · DUPLICATE — alla färgkodade.

🚦

Ready-for-treatment

/missing?treatment=fue returnerar vilka formulär krävs, vilka finns, vilka blockerar.

Säkerhetsegenskaper som hålls genom hela kedjan för Hair TP Clinic: Ingen Drive-länk i UI (verifierat via smoke-tests). Ingen extern AI på journalinnehåll. All PDF i CCO secure storage med SHA-256-checksum + tamper-hash. Signerad journal kan aldrig ändras tyst (locked-guard testat). Audit-kedja: form_submitted → form_signed → pdf_archived → asset_imported → asset_status_transition. RBAC per endpoint (owner / operator / konsult / personal). Mobile-first design — patientportalen fungerar på telefon.
