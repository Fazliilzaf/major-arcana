Snabbtips för presentationen:
Tryck Cmd+K för global kundsök. Cmd+Z ångrar senaste (tid-maskinen). Klicka 🎤 mikrofonen för voice booking ("Boka Anna PRP tis 14"). Hover korta bokningar → kundnamn dyker upp.

Demo-checklist · vad du klickar i vilken ordning: Öppna /onboarding-tour.html först → klicka igenom 5 slides → klickar "Sätt igång!" → landar i /kalender.html Morgon-vy → klicka Vecka → drag-omboka en bokning → klicka 📷 Ta bild på en kund → fota → annotera → spara → byt till /major-arcana-preview/?view=customers → klicka Anna Karlsson → utforska dossiér → byt till /konversationer.html → läs Annas tråd → byt till /analytics.html → visa intäkts-charts. ~5 min total.
