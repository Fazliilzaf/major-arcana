## Hur kön fungerar

1. Fazli skickar UI-önskemål (text + screenshot)
2. Claude implementerar ändringen i `cco-polish.css` (eller patient-master-ui.js) lokalt
3. Claude bekräftar "tillagd i kön" + visar diff-stat
4. Claude INTE pushar, INTE deployar
5. När Fazli säger "deploy nu" / "kör kön" — Claude pushar EN commit med ALLA samlade ändringar + triggar EN deploy
