### Fas 3: SIGABRT 134-grävning (trippel-fix)

Symptom: Crash-loop var 18–22 min med samma instance-ID, auto-restart fångade det.

**Root cause:** Tre olika kodvägar laddade Graph API-data med för stort lookback-fönster.

| Commit | Lager | Lookback (före → efter) |
|---|---|---|
| `772d363` | Frontend `/runtime/history` endpoint | 1095 → 90 d |
| `2a26a7b` | Scheduler `backfillLookbackDays` | 1095 → 90 d |
| **`949bd6c`** | **Bootstrap-backfill (rotorsaken)** | **90 → 14 d** |

**Bootstrap var boven:** vid varje restart laddade den 4340 messages från contact-mailbox × 4 folders × 6 mailboxar i ETT svep → flera GB i memory → OOM på Standard 2 GB → kraschloop.

**Verifierat live:** 25+ min efter `949bd6c` deploy = ingen ny `Instance failed`-event (mot förväntade 2 enligt gamla mönstret).
